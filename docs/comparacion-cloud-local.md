# Comparacion despliegue local y nube
Docker local: el estudiante administra host, parches del equipo, contenedores, almacenamiento, copias de seguridad y credenciales. Los contenedores NO son servicios gestionados.
En AWS se puede evaluar Amazon DocumentDB (compatibilidad MongoDB limitada), Amazon Neptune (grafos, lenguaje y modelo no identicos a Neo4j) y Amazon Keyspaces (Cassandra compatible). En Azure: Cosmos DB for MongoDB (compatibilidad a evaluar) y servicios o despliegues de terceros para grafos/Cassandra. En Google Cloud: MongoDB Atlas o Neo4j Aura como servicios de terceros y alternativas gestionadas especializadas; verificar compatibilidad y disponibilidad antes de contratar. La administracion compartida y el control de acceso siguen requiriendo configuracion del cliente.
