# Arquitectura
SQL Server (Unidad I): datos transaccionales de estudiantes, servicios y solicitudes.
MongoDB: documentos extendidos por codigo de servicio.
Neo4j: relaciones de estudiante a servicio.
Cassandra: eventos consultables por estudiante y fecha.
Docker Compose: contenedores aislados, volumenes persistentes y una red interna. No se implementa API ni cluster.
